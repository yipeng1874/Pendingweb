# todo-h5

独立于现有 PC 项目的 H5 我的待办前端。

## 当前已实现
- 账号密码登录
- 飞书登录入口与回调处理
- 登录后身份选择
- 我的待办列表
- 七类待办展示及填写：主播日常、厅管日常、触达式、主播式、管理式、流转任务、厅内直达
- 图片上传前自动压缩：超限照片按比例缩小并转为 JPEG，预览确认后上传；1MB 内的支持格式保持原文件，失败可重试

## 当前原则
- 不改现有 `frontend` 项目页面文件
- 复用现有后端 API
- 先跑通 `登录 -> 身份 -> 我的待办` 主链路

## 启动
```bash
cd todo-h5
npm install
npm run dev
```

默认开发端口：
- `http://localhost:4173`

代理后端：
- `/api -> http://127.0.0.1:4000`

## 图片压缩验证
启动开发服务后，打开 `http://localhost:4173/tests/imageCompression.html`。
测试在浏览器本地生成图片，不发送上传请求，覆盖大图压缩、尺寸比例、小图原样返回、EXIF 竖拍方向、透明背景及异常格式。

HEIC/HEIF 需要浏览器能解码；不支持时会提示改用 JPG/PNG/WebP。超过 1MB 的 GIF 不自动转成静态图。

## 待办填写规则

| 类型 | 填写入口及完成方式 |
| --- | --- |
| 主播日常、触达式、主播式、管理式 | 点击任务进入详情；问答、单选、多选、待办确认、学习链接、图片上传复用普通待办接口。必填项完成后可在底部提交；后台也会在全部子项完成时自动完成。 |
| 厅管日常 | 点击任务进入详情；使用厅管专属保存和上传接口，必填项完成后自动提交，失败时可在底部重试。支持次日北京时间 16:00 前补录。 |
| 流转任务 | 展开后填写本人负责且未完成、未截止的节点。待办题填写完成情况说明；逐题确认，全部必填题确认后自动完成节点。其他人的节点只读。 |
| 厅内直达 | 展开后逐题确认，全部必填题确认后自动完成；已结束或已截止时只读。 |

流转任务和厅内直达共用六种题型编辑器，已确认答案只读。附件支持图片及后台允许的 PDF、Word、Excel、MP4、MOV，单文件上限 20MB；静态照片超过 1MB 自动压缩并预览，GIF 保留原图。普通任务及厅管日常图片仍限 1MB。

已提交的个人任务、日常任务只读；组织临时任务保留提交后补充能力。厅管请假待审核或已批准、主播日常已豁免时只读。未确认输入保留在当前展开页面，离开页面前请先确认保存。

## 填写流程验证

启动开发服务后打开 `/tests/taskFilling.html`。浏览器测试使用模拟接口，覆盖七类入口、六种题型、失败重试、图片/文档上传关联、自动完成及完成分组、权限和补录规则、手机宽度溢出检查。`/tests/taskFilling.html?preview` 可查看模拟流转填写界面。这些测试不代替真实账号的后端联调。

页面加载回归可打开 `/tests/pageLoading.html`，验证真实仪表台路由懒加载及空模块异常的恢复提示。开发服务等待文件写入稳定后再更新模块，避免保存过程中短暂的空文件进入转换缓存。
